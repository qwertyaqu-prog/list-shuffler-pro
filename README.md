# List Shuffler Pro

Aplikasi berbasis desktop (GUI) menggunakan Python dan Tkinter untuk merapikan, membagi, dan mengacak baris teks (list) lalu mengekspornya langsung ke format file Excel (`.xlsx`).

## ✨ Fitur Utama
* **Input Real-time Counter:** Menghitung total baris teks secara langsung.
* **Dual Mode:** Mode target jumlah kolom atau mode batas item per kolom.
* **Shuffle:** Fitur opsional untuk mengacak data sebelum diproses.

## 🚀 Cara Menjalankan
1. Instal library pendukung: `pip install openpyxl`
2. Jalankan script utama: `python list-shuffler-pro.py`
